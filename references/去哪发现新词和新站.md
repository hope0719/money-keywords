# 去哪发现新词和新站

SKILL.md 的主办法是「拿词根看谷歌趋势的相关查询，留下的词再看谷歌前 20 名、查注册日期」。这一份讲两件事：没有方向时去哪找新名字；主办法之外，还有哪些办法能看到新词和新站。

> 这份里凡是讲「排进前 30」「排第几」的实测数，当时用的是一个付费接口取的名次。2026-11-17 核对发现它和真实谷歌对不上，这些数已经删掉或标了「待重查」。站、注册日期、搜索量的数不受影响。

## 一、新东西先在哪出现

一个新东西冒出来，各处看得见它的先后大致是这样。越靠上越早。

| 在哪看得见 | 比谷歌上看得见早多少 | 去哪看 |
|---|---|---|
| 发布前的泄露、匿名测试、代号 | 有明确发布时刻的，中位早 4 天，最长 9 天 | X 上最早发消息的账号；模型评测榜上的匿名模型 |
| 有人开始拿它做东西 | 慢慢传开的那种，中位早约 50 天 | GitHub 趋势榜；创建不到两周、星数涨得快的仓库 |
| 各个平台的新条目 | 发布当天 | Hugging Face 的热门模型和 Spaces；Replicate、fal 的新模型页；Product Hunt；Show HN；应用商店榜单；Steam 新品榜 |
| 社交媒体上很多人在跟 | 比谷歌趋势早 | X 高级搜索：近 24 小时、点赞多、带链接的帖；Reddit 一周内的新帖 |
| 谷歌下拉 | 发布后约半天就有 | 名字后面加 a 到 z |
| 同名域名被注册 | 和谷歌上看得见几乎同时 | 见第三节 |
| 谷歌趋势 | 已经晚一拍 | 近 30 天上升的相关查询 |
| 关键词工具的月度量 | 晚一到两个月 | |

没有方向时，从上面第三、四行找 3 到 5 个最近一个月的新名字就够了。页面打不开就换下一处，都打不开照实说。

游戏的新名字另有去处：itch.io 的最新网页游戏、Newgrounds 的最新游戏、Steam 的新品。怎么用见 SKILL.md 第 2 步「游戏另走一路」。

找名字时守三条：

- 只收最近一个月出现、而且作者以外有别人在跟的：有人转、有人问、有人拿它做了东西。
- 叫法从别人的帖子和回复里照抄，不自己起名。社媒上热、搜索框里还没有这个名字的，先放着，过几天再看下拉。
- 社媒热不等于有人搜。实测一个帖子 13,766 分、5,861 条评论，前 100 条里没有一个人在问怎么做。
- 一个功能太新、还没人搜它的名字时，先找已经有人搜的上一级说法。比如 AI 记笔记还没人搜的时候，人们搜的是记笔记工具。

## 二、怎么认一个词是新词

| 办法 | 怎么做 | 要留意 |
|---|---|---|
| 看每月的量 | 查最近 12 个月每月的量。最近一个完整月 200 次以上，而它前面隔一个月的那个月不到它的 5% | 最直接。数会晚一两个月。自己按月算，不照抄工具给的标签 |
| 看谷歌趋势的上升查询 | 方向相关的大词，看近 30 天上升的相关查询。标 Breakout 的是涨了几十倍以上的 | 一次只给约 25 条；近 1 天、近 7 天的常常是空的 |
| 看名字第一次出现的日期 | 官方发布页、模型页、最早的报道 | 两到四个月的单分一档，超过四个月的照老词看，见 SKILL.md 第 4 步 |
| 两条线同时抬头才当真 | 趋势、下拉、第一页里，至少两样都看得到 | 工具里一个词突然涨几十倍，先怀疑是工具算法变了 |

## 三、主办法之外，还能怎么发现新站

新站指注册一年以内的；近两个月注册的叫「很新」，它们多数还排不上去。下面第一个办法是 SKILL.md 第 5 步规定要做的，第三个是第 6 步的滚雪球，其余是可选的。

| 办法 | 怎么做 | 实测和用法 |
|---|---|---|
| 拿新词拼域名去查 | 新词去掉空格或加连字符，配 com、ai、app、io、org、net 这些后缀，用 `https://rdap.org/domain/拼出来的域名` 查有没有人注册、哪天注册的 | 59 个新词查到 82 个近两个月注册的域名。它告诉你有多少人在抢这个名字。查到的要打开看，同名域名做的常常不是这个东西 |
| 证书透明记录 | 打开 `https://crt.sh/?q=%25新词去掉空格%25&output=json`，看名字里带新词的域名各是哪天第一次签证书的，再查注册日期 | 能看到刚上线几天的站，多数还没有内容，要点开看是不是活的 |
| 从已经找到的新站滚雪球 | 看它的导航和站点地图还有哪些页面；查它排上了哪些词；把这些词再拿去搜，又能捞到别的新站 | 能翻出一开始想不到的词 |
| 隔几天看一次对手的站点地图 | 记下新加的页面 | 新页面不等于新词。实测一个大站新增的 59 个页面，17 个早有存档 |
| 工具导航站的榜单 | 看月度榜单和新收录，挑排名靠后、自然搜索占比高的 | 榜首都是大产品，往后翻才有小站 |
| 流量增长榜 | 按月环比增长排的网站榜 | 上榜的多是中大型站，有最低流量门槛，很新的小站看不到 |
| 工具导航站过去一周的新页面 | 谷歌搜 `site:导航站的域名 intitle:generator`，时间选过去一周。几个站同一天在做同一个词的，记下来 | 外部分享的做法：有人这样看到两个站同一天提交同一个功能，定价也一样 |
| 托管平台上新冒出来的免费子域名 | 很多人先用免费子域名上线试需求。有流量工具的，在托管平台的域名上看最近几个月新出现、已经有搜索流量的子域名 | 外部分享的做法，我们没有实测 |
| 新站榜 | 有人做了每天更新的榜：注册不满 90 天、已经有搜索访问的站，按日均访问排 | 外部产品，访问量是估算的 |
| 它哪天开始收钱 | 一个站第一次挂出付款链接的那天，算它开始卖东西的日子 | 外部的一次核对：2000 条最新的付款链接里，约三分之二来自早就在卖的老站。最新的链接不等于新站 |
| 老站最近三个月的新页面 | 有付费工具的，看一个对手最近三个月新拿到流量的页面；没有的，看它站点地图里带 compare、vs、alternative 的新网址 | 找到的是老站正在抢的新词 |

## 四、看到一个新站，问五件事

| 问什么 | 怎么查 | 为什么问 |
|---|---|---|
| 它哪天注册的，多久排上去的 | 注册日期对比它现在的名次 | 几个月就排上去的，这个词新站进得去 |
| 它接到了哪些词 | 查它排进前 20 的词，或看站点地图 | 找它验证过的词和词型 |
| 它的访问从哪来 | 有流量工具的，看搜索、直接访问、付费广告各占多少 | 靠买广告起来的，不能说明这个词好排 |
| 它怎么收费 | 价格页 | 收不收得到钱的参照 |
| 它是不是只靠一个词 | 看它排上的词有几个 | 只靠一个名字或一个季节词的，学它的词，不学它的站 |
| 它的名次稳不稳 | 隔一两周再搜一次 | 新站刚被谷歌发现时，常有一段短暂的上升，之后可能掉下去 |

对标站挑比你领先一点的小站，不挑大站。大站只用来看它顾不过来的角落。域名注册得早不等于项目做得早。但分档一律按域名注册日期算：老域名被人买来重做的不算新站，在备注里记一句它是哪天重做的。

**排上去不等于有流量。** 对标站要挑在做一批词的，不挑只做一个词的。这一条原来引的实测数待重查。

## 五、几个数，用来校准预期

| 数 | 说明什么 | 出处 |
|---|---|---|
| 10 万个词的谷歌前 10 里，注册不到两年的域名只占 2.03%，前 3 只占 1.42% | 新站排上去是少见的事，看到了就值得细看 | 一家 SEO 工具公司 2026 年 5 月的统计 |
| 一个注册一年的站，排进前 10 的 75 个词平均难度 13，月搜索量最大的 590 | 新站先排上去的是窄的、难度低的词 | 同上 |
| 第一页专门做这件事的站，0 到 2 个还有机会，5 个以上算晚 | 追一个新名字时的一条经验线。老词不适用：老词第一页站多很正常，要看的是里面有没有新站 | 一位公开分享做法的作者 |

## 六、谷歌趋势以外的来源，实测过哪些有用

2026-11-17 拿一个新手机的壁纸方向，逐个试了一遍。

| 来源 | 实测拿到什么 | 有没有用 | 用在哪 |
|---|---|---|---|
| 应用商店，按上架日期搜 | 近一个月 9 个新的同类应用，名字、上架日、评分数都有 | 有用 | SKILL.md 第 2 步必看。看有多少人正在进、应用名里带什么词 |
| X 上按方向搜帖子 | 15 条高赞帖，14 个应用和站的名字，有人挂出收费的壁纸包，真人的原话。没有回原帖核对 | 有用，要能搜 X | 第 2 步；名字给第 6 步，原话给第 7 步 |
| X 上近 7 天、点赞过千、带外链的发布帖 | 12 个新产品的名字和域名 | 有用 | 用户没给方向、要找新名字的时候，见第一节 |
| 谷歌趋势切到图片搜索 | 上升栏是题材和节日，有当月两万多次的词 | 靠看图的方向有用 | 第 2 步，看方向切 |
| 谷歌趋势切到 YouTube 搜索 | 「how to」开头的难处，每月几百次 | 找差别时有点用 | 第 2 步，看方向切 |
| YouTube、图片搜索的搜索框联想 | 和谷歌下拉差不多，多出 setup、tutorial 这类说法 | 用处不大 | 不单独看 |
| X 的热门趋势榜 | 60 个话题里 2 个像产品名 | 没用 | |
| 谷歌趋势的「正在流行」 | 10 条全是天气、球赛、股票、每日字谜 | 没用 | |
| Exploding Topics 的免费页 | 只给 6 个话题，多是实物商品 | 没用 | |
| Hacker News | 消费类方向近 60 天没有过 5 分的帖子 | 消费类方向没用，开发者工具方向有用 | |
| Pinterest 趋势 | 首页不登录能看，是家居、穿搭、节日；搜具体的词要登录 | 没查成 | |
| TikTok 的关键词洞察 | 要登录 | 没查成 | |
| 必应的搜索框联想 | 公开的那个地址没取成 | 没查成 | |

三处有用的来源都不给搜索量。它们冒出来的新应用的名字，挑两个查量，每月都不到 10 次。所以它们补的不是词，是谷歌趋势看不到的三件事：谁正在进、有没有人在卖、真人怎么说。
